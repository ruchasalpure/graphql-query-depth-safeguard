# Duties and Responsibilities for GraphQL Query Depth Safeguard Agent

## Dual-Control Architecture
Maker:
ast-depth-calculator

Checker:
complexity-budget-checker

## Operational Workflow
1. The Maker (ast-depth-calculator) analyzes incoming telemetry, context, and requirements.
2. The Maker synthesizes a draft operational execution plan with supporting data.
3. The Checker (complexity-budget-checker) independently verifies all assumptions and constraints.
4. If validation passes, the plan is signed, logged, and committed.
5. All actions are appended to the immutable governance audit trail.
